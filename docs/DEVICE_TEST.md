# 실기기 점검

헤드리스 테스트와 데스크톱 측정으로는 실제 폰의 GPU, 메모리 한도, 발열, 터치 감각을 알 수 없습니다. 이 문서는 실제 기기에서 무엇을 어떻게 확인하고 기록할지 정합니다.

## 준비

- 주소: 배포 주소 뒤에 `?perf=1`을 붙이면 왼쪽 위에 성능 표시가 나옵니다. 키보드가 있으면 F3으로 켜고 끕니다(`scripts/ui/perf_overlay.gd`).
  - 1줄: 초당 프레임, 평균 프레임 시간(ms), 0.5초 동안 가장 긴 프레임, 50ms를 넘은 프레임(멈춤) 누적 수
  - 2줄: 드로 콜 수, 그린 삼각형 수(천 단위)
  - 3줄: 비디오 메모리, 엔진 메모리(MB)
  - 4줄: 화면 크기와 창 크기, 그래픽 품질(HQ/LQ), 배터리 절약(30fps)
  - 5줄: 안전 영역(노치·둥근 모서리·홈 표시줄이 가리는 가장자리, 캔버스 단위). 노치 있는 폰에서 0이면 `viewport-fit=cover`가 먹지 않은 것입니다.
  - 6줄: GPU 이름
  - 7줄(전투 중): 적 수, 병사 수
- 노치가 없는 기기에서 노치 배치를 보려면 주소 끝에 `?safe=왼,위,오른,아래`(캔버스 단위)를 붙입니다. 예: 아이폰 세로 `?safe=0,66,0,38`, 가로 `?safe=64,0,64,28`. 데스크톱에서는 `DISPLAY=:77 UISAFE=64,0,64,28 tools/ui_shots.sh <폴더> 2 L`.
- 첫 방문을 다시 재려면 사이트 데이터를 지웁니다(크롬: 사이트 설정 → 데이터 삭제, 사파리: 설정 → 사파리 → 고급 → 웹사이트 데이터). 저장도 같이 지워지므로 먼저 설정 → 저장 코드 내보내기로 진행을 옮겨 둡니다.
- 결과는 아래 기록 양식에 적고, 이상한 판은 설정 → 플레이 기록 보내기 코드(주소 끝에 `?dev`를 붙여 연 테스터 모드에서만 보임)와 스크린샷을 같이 남깁니다.

## 기기 목록

| 구분 | 예 | 볼 점 |
|---|---|---|
| iPhone 구형 | iPhone 11, SE 2세대(사파리) | WebGL 메모리 한도로 탭이 다시 로드되는지, 발열 |
| iPhone 최신 | iPhone 15 이상(사파리) | 120Hz에서의 프레임 고르기 |
| Android 저가 | 갤럭시 A1x급(크롬) | 프레임, 텍스처 형식(ETC2), 로딩 시간 |
| Android 중·고급 | 갤럭시 S·A5x급(크롬) | 기준 성능 |
| 태블릿 | iPad(사파리), 안드로이드 태블릿 | 가로·세로 배치, 큰 화면의 글자 크기 |
| 데스크톱 | 크롬, 사파리, 파이어폭스, 엣지 | 키보드 단축키, 창 크기 바꾸기 |

## 점검 항목(기기마다)

1. **첫 방문 로딩**: 주소를 연 때부터 타이틀까지, 첫 전투가 시작될 때까지 걸린 시간. 로딩 진행 표시가 멈춘 것처럼 보이는 구간이 있는지.
2. **소리**: 첫 탭 뒤에 음악과 효과음이 나오는지(iOS는 무음 스위치도 확인). 음악이 반복될 때 끊기는지. 전투 음악이 지역마다 바뀌는지.
3. **전투 프레임**: 1지역 마지막 웨이브와 5지역(트롤) 보스 웨이브에서 성능 표시의 프레임, 가장 긴 프레임, 멈춤 수.
4. **처음 그릴 때의 멈춤**: 첫 타워 건설, 첫 업그레이드, 처음 보는 적이 나올 때 멈춤 수가 늘어나는지. 늘면 그때의 행동을 적습니다(셰이더 워밍업에 빠진 것, `docs/PERFORMANCE.md` 7절).
5. **메모리**: 지역 세 개를 이어서 했을 때 비디오·엔진 메모리. 사파리에서 탭이 저절로 다시 로드되면 그 지점.
6. **입력**: 탭, 드래그, 핀치 줌. 원형 건설 메뉴를 잘못 누르는 일이 있는지. 영웅 이동 탭이 잘 먹는지.
7. **화면**: 노치와 홈 표시줄에 UI가 가리지 않는지(성능 표시의 안전 영역 줄이 기기 값과 맞는지). 가로·세로를 돌렸을 때 배치. 설정의 UI 크기(작게·보통·크게)별 글자.
8. **백그라운드**: 다른 앱으로 갔다가 돌아오면 일시정지되어 있는지, 소리가 다시 나는지. 페이지가 숨겨지면(`visibilitychange`, `pagehide`) 저장하고 전투를 멈춥니다(`Game.backgrounded`). 창 포커스가 빠질 때만 오는 엔진 알림은 모바일 사파리의 앱 전환에서 오지 않을 수 있어 따로 봅니다.
9. **저장**: 탭을 닫고 다시 열어도 진행이 남는지. 저장 코드 내보내기·가져오기. 사생활 보호(시크릿) 모드나 사이트 데이터 차단에서는 타이틀에 "진행이 저장되지 않는 브라우저입니다" 알림이 뜨고, 그 밖의 오류는 없어야 합니다.
10. **발열·배터리**: 20분 플레이 뒤 배터리 감소와 손에 느껴지는 열. 배터리 절약(30fps)을 켰을 때의 차이.
11. **홈 화면 앱(PWA)**: 홈 화면에 추가한 뒤 실행, 비행기 모드에서 다시 실행.

## 미리 알려진 위험

- iOS 사파리는 탭 하나가 쓸 수 있는 WebGL 메모리가 작아서, 지역을 여러 번 오가면 탭이 다시 로드될 수 있습니다. 5번 항목에서 확인합니다.
- 저가 안드로이드에서는 그래픽 품질이 자동으로 낮음(LQ)으로 시작합니다. HQ로 바꿨을 때도 봐 둡니다.
- 데스크톱 측정(llvmpipe)에서는 1·2·4·5·11지역 모두 전투 중 셰이더 컴파일이 0개입니다. 실기기 드라이버는 같은 프로그램도 다르게 다룰 수 있으니 4번 항목에서 멈춤 수를 꼭 봅니다.
