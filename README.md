# Rune Bastion · 룬 바스티온 — 3D 판타지 타워 디펜스 (Godot 4.7)

Kingdom Rush · Bloons TD 6 계열(경로형 타워 디펜스 + 영웅 + 스킬 + 타워 전문화)을 레퍼런스로 만든 웹/모바일용 3D 디펜스 게임입니다.

**▶ 웹에서 플레이: https://kosj.github.io/rune-bastion-defence/** (데스크톱·모바일 브라우저. 홈 화면에 설치하면 오프라인으로도 실행됩니다)

## 실행 방법
- **Godot 에디터**: Godot **4.7.2** 이상에서 `project.godot`을 엽니다. 처음 열면 에셋 임포트가 끝난 뒤 F5로 실행합니다.
  - 모델 텍스처(`*_albedo/normal/orm.png`)는 첫 임포트 때 GLB에서 자동으로 추출되므로 저장소에는 넣지 않았습니다. 역할별 압축 설정은 `python3 tools/patch_imports.py`로 적용합니다(`tools/build_web.sh`가 자동으로 실행합니다).
- **웹 빌드**: `gh-pages` 브랜치에 배포된 정적 파일을 그대로 다른 정적 웹서버에 올려도 됩니다(itch.io, Netlify 등). 단일 스레드 빌드라서 COOP/COEP 헤더가 필요 없습니다. 로컬에서는 `python3 -m http.server`로 열 수 있고, `file://`로 직접 열면 동작하지 않습니다.
- **Android / iOS**: `export_presets.cfg`에 프리셋이 들어 있습니다. Godot에서 Android SDK/JDK(iOS는 Xcode)와 Export Templates를 설치한 뒤 내보내면 됩니다.

## 게임 구성
| 구분 | 내용 |
|---|---|
| 지역 | 10개: 그린베일 고개(튜토리얼) → 쌍둥이 여울 → 서리바람 고개 → 달빛 숲 → 트롤왕의 협곡(보스) → 검은 성채 → 통곡의 폭포 → 망자의 신전(보스) → 폭풍 항구(두 갈래 상륙로) → 왕도 최후의 방어선(세 갈래, 최종 보스). 지역마다 10~16웨이브, 쉬움/일반/영웅 난이도 |
| 스토리 | 지역에 처음 들어가면 경비대장 브란·영웅·보스가 주고받는 짧은 대화(초상화, 타자 효과, 탭으로 넘기기, 건너뛰기)가 나온 뒤 오프닝으로 이어집니다. 최종 지역을 처음 깨면 에필로그가 나옵니다 |

| 타워 | 궁수 / 병영 / 마법사 / 포병. 각각 3레벨이고, 3레벨에서 전문화 2종 중 1종을 고릅니다(총 8종) |

| 특수 능력 | 전문화마다 1종 추가 습득: 독 화살, 처형 사격, 신성한 일격, 투창 세례, 차원 이동, 절대 영도, 충격 포탄, 네이팜 탄두 |
| 적 | 고블린, 주술사(치유), 폭탄병(자폭), 다이어 울프(고속), 오크 돌격병(중장갑), 오크 족장(전투 함성), 가고일(비행), 바위 오우거(내려찍기 기절), 트롤 군주(보스·격노), 해골 병사, 해골 기사(한 번 부활·마법 약점), 리치 군주 모르가스(보스·해골 소환), 오우거 왕 고르막(최종 보스·내려찍기·전투 함성·격노 시 오우거 친위대 소환) |
| 영웅 | 엠버 기사 카엘(근접 탱커), 별빛 마법사 세라(원거리 마법), 숲의 사수 렌(원거리 물리·방어 관통, 스킬 화살비: 화살 16발로 넓은 범위 타격·둔화. 4번째 지역 클리어 시 해금). 전투 경험이 누적되어 등급이 오르고, 등급마다 재능 포인트로 체력·공격력·스킬·재사용 재능(각 3단계)을 찍습니다 |

| 연출 | 첫 방문 때 포털에서 성문까지 길을 따라가는 오프닝, 보스 등장 컷신(레터박스·슬로모션·이름 카드), 보스 처치 슬로모션, 강타 예고 표시, 승리 때 환호와 불꽃놀이, 패배 때 흑백 슬로모션. 컷신은 탭하면 건너뜁니다 |

## 다국어
- 코드의 문자열은 한국어 원문이고, 영어는 `scripts/i18n/lang_en.gd`(원문 → 번역)로 런타임 `Translation`을 만들어 씁니다. 언어는 브라우저/OS 언어를 따르고 설정에서 바꿀 수 있습니다.
- 번역 원본은 `tools/i18n/en_*.txt`(탭 구분)입니다. 텍스트를 추가했다면 `python3 tools/i18n_build.py`로 테이블을 다시 만들고 빠진 문자열을 확인한 다음, `python3 tools/make_fonts.py`로 폰트 서브셋을 다시 만듭니다.

## 웹 배포 (모바일·PWA)
- **나눠 받는 데이터 (첫 로딩)**: 각 팩은 작은 **코어 팩**(스크립트·UI·폰트·효과음·음성·메뉴 음악·타이틀 배경, 약 9MB)과 **콘텐츠 팩**(`*_content.pck`: 3D 모델·캐릭터·전투 음악, 약 61MB)으로 나뉩니다(`tools/split_pck.py`). 셸은 엔진과 코어 팩만 받으면 바로 게임을 시작하고, 타이틀 화면이 떠 있는 동안 콘텐츠 팩을 이어서 받습니다. 게임은 도착하는 즉시 `ProjectSettings.load_resource_pack()`으로 붙입니다(`scripts/autoload/content.gd`). 그 사이 타이틀에는 같은 카메라 구도로 미리 렌더링한 디오라마 그림(`assets/ui/backdrop`, `tools/render_backdrops.sh`)이 깔리고, 콘텐츠가 붙으면 3D 장면을 몇 프레임에 나눠 짓고 나서 교차 페이드로 바꿉니다. 콘텐츠가 오기 전에 출전을 누르면 진행 막대가 있는 ‘전장을 준비하는 중’ 카드가 떠서 기다립니다. 20Mbps 회선에서 타이틀 화면까지 41.6초 → 10.5초입니다. 다시 방문하면 서비스 워커 캐시에서 둘 다 바로 읽습니다.
- **두 가지 데이터 팩**: 데스크톱은 `index.pck`(WebP 텍스처), 폰·태블릿은 `index_mobile.pck`(ETC2/EAC GPU 압축 텍스처, 화면 크기에 맞춘 해상도 상한)를 받습니다. 셸이 기기와 `WEBGL_compressed_texture_etc` 지원을 확인해서 고르고, `?pack=mobile|desktop`으로 강제할 수 있습니다. GPU 메모리를 4~8배 덜 씁니다.
- **폰 전용 메시**: 모바일 팩에는 타워 12종·성·포털을 삼각형 35~45% 수준으로 다시 만든 버전(`mobile/models`, 노멀맵 재베이크)이 들어갑니다. `tools/build_web.sh`가 모바일 팩을 만들 때 바꿔 넣고, 데스크톱 빌드는 `.gdignore`로 무시합니다.
- **LOD**: Godot의 자동 메시 LOD를 씁니다(캐릭터). 저사양 설정(모바일 기본값)에서는 LOD 허용 오차를 4px로 늘리고 3D 해상도 80%, 그림자 1단계로 그립니다.
- **삼각형 예산**: 타워·성·포털·나무·소품은 UV가 잘게 나뉜 베이크 메시라 엔진이 LOD를 만들지 못합니다. 그래서 게임 카메라에서 보이는 크기(가장 가까운 줌에서 타워 100~200px)에 맞춰 타워 7.5k~10k, 성 14k, 포털 11k, 나무 1.5k~2.4k, 무기 0.6k~0.9k로 직접 줄였습니다(`rebuild_assets.sh`). 가장 가까운 줌의 스크린샷에서 이전 메시와 차이가 나지 않는 선입니다. 장면 전체 삼각형이 약 40% 줄었습니다.
- **프레임 비용**: 화면 밖 유닛은 스켈레톤 애니메이션을 멈추고(`VisibleOnScreenEnabler3D`), 저사양의 유닛 발밑 그림자는 하나의 MultiMesh로 그립니다(`BlobLayer`, 유닛 수만큼이던 드로우 콜이 1개로). 파티클은 30Hz로 시뮬레이션하고 보간합니다.
- **해상도 자동 조절**: 프레임이 계속 목표의 80% 아래면 3D 해상도만(UI는 그대로) 10%씩 낮추고, 여유가 생기면 설정값까지 되돌립니다(`ResGuard`, 최저 60%). 해상도를 낮춰도 빨라지지 않으면(GPU가 병목이 아니면) 바로 되돌리므로 충분히 빠른 기기에서는 아무것도 바뀌지 않습니다.
- **측정**: `browser_test.py <폴더> <출력> --play --throttle=20 --nosw`가 회선 속도를 제한한 브라우저에서 엔진 시작·타이틀·콘텐츠 도착·전투 시작 시각을 찍습니다(`--early`: 콘텐츠가 오기 전에 출전). 네이티브에서는 `test_runner.tscn -- mode=menu content_pack=<콘텐츠 팩> content_delay=초`로 늦게 도착하는 콘텐츠를 흉내 냅니다. `test_runner.tscn -- perf=시작,초`가 프레임 시간·스크립트 시간·드로우 콜·삼각형 수를, `lodprobe=초 groups=1`이 메시별 삼각형·드로우 콜을 출력합니다.
- **PWA**: `manifest.webmanifest`와 서비스 워커(`web/sw.js`)로 홈 화면에 설치하고 오프라인으로 실행할 수 있습니다. 데이터 파일은 빌드 ID(`?v=`)로 버전을 매겨 캐시에서 바로 읽고, 새 버전을 배포하면 자동으로 교체됩니다.
- **자동 배포**: `.github/workflows/deploy-web.yml`이 `main`에 푸시될 때마다 Godot으로 빌드해 `gh-pages`에 올립니다.

## 에셋 파이프라인
- **원본 생성 (NCSOFT VARCO 3D)**: 컨셉 이미지 → 3D 메시 → (캐릭터는) 자동 리깅·애니메이션. 타워 12종·성·포털·건설 부지는 **고폴리(6만~8만 삼각형) + 2048 텍스처**로 다시 생성했습니다.
- **게임용 변환 (`tools/pipeline/rebuild_assets.sh`, Blender 4.5 헤드리스)**: 원본 다운로드 폴더에서 전체 에셋을 다시 만듭니다(`RAW=<원본 폴더> ./tools/pipeline/rebuild_assets.sh <출력 폴더>`). VARCO 원본(약 400MB)은 저장소에 넣지 않았습니다.
  - `process_hq.py` (건물·소품): 고폴리 원본을 엣지 콜랩스로 게임 예산(타워 1.4만~2만, 성 3만)까지 줄입니다. 46° 이상 꺾인 모서리는 하드 엣지로 두고 면적 가중 노멀을 적용합니다. 고폴리 디테일은 노멀맵으로 베이크합니다(적응형 케이지, 뒤집힌 텍셀 보정, 검증 실패 시 원본 맵 사용). 게임 메시의 AO도 베이크합니다.
  - `merge_character.py` (캐릭터): 애니메이션별 GLB를 하나로 합치고 공격 모션을 타격 순간 기준으로 잘라냅니다. 레스트 포즈 상태로 AO를 베이크합니다.
  - `tex_roles.py`: 텍스처를 역할(albedo / normal / orm)별 PNG로 내보냅니다. 생성형 AI가 만든 잘못된 PBR 값도 바로잡습니다. AO 채널이 상수 1.0이던 것은 베이크한 AO로 바꿉니다. 돌·나무·천에 0.2~0.5로 들어가 있던 금속도는 확실한 금속만 남깁니다. 노멀맵 B 채널은 Godot가 쓰지 않으므로 평탄화해 압축률을 높입니다.
  - `tools/patch_imports.py`: Godot 임포트 설정을 역할별로 지정합니다. albedo는 WebP 손실(0.92), normal과 ORM은 무손실입니다. WebP 손실 압축은 YUV 4:2:0이라 노멀 방향이 평균 2.5~6° 틀어집니다.
  - `render_glb.py`: 전후 비교용 Cycles 렌더입니다.
- **런타임 (`scripts/core/assets.gd`)**: 텍스처에 비등방성 필터링을 적용하고, AO가 직사광에도 40% 반영되게 합니다. 톤매핑은 Filmic(화이트 포인트 2.0)이고, 데스크톱은 MSAA 4x입니다.
- 캐릭터 모션: 피격(hit), 고블린 사망 2종, 해골 기사의 일어서기(rise), 병사 환호(cheer), 보스 등장 동작(트롤 가슴 두드리기, 리치 팔 벌리기, 오우거 왕 도발), 리치 시전(cast)을 VARCO 애니메이션으로 추가했습니다. 늑대는 메시를 리메시한 뒤 4족 리깅으로 질주·사망 모션을 붙였습니다. 가고일은 리깅 없이 날갯짓 연출을 코드로 처리합니다.
- **UI 아이콘**: `make_icons.py`(PIL 벡터 드로잉)로 그렸고, 타워 썸네일과 초상화는 Godot에서 렌더링했습니다(`scenes/icon_render.tscn`).
- **음악**: `make_music.py`에 직접 작곡한 곡 4개(메뉴, 전투, 어둠 지역 전투(6/8), 보스)와 큐 7종(승리, 패배, 웨이브 뿔나팔, 보스 등장, 레벨업, 강화, 별)을 음표 데이터로 적었습니다. `sf2synth.py`(numpy로 직접 만든 SoundFont 샘플 플레이어)가 General MIDI 사운드폰트 [GeneralUser GS](https://github.com/mrbumpy409/GeneralUser-GS)(S. Christian Collins, 상업적 사용 허용)로 렌더링합니다. 루프 곡은 세 번 렌더링해 가운데 회차를 잘라 이음매가 없습니다: `python3 -I tools/pipeline/make_music.py GeneralUser-GS.sf2 <출력 폴더>`. 사운드폰트 파일은 저장소에 넣지 않았습니다.
- **소품 메시**: 무기(검, 도끼, 몽둥이, 단검), 포병탑 박격포, 운석, 고블린 주술사의 수정, 마법사탑의 떠 있는 수정도 VARCO 이미지→3D로 만들어 정적 메시와 같은 파이프라인(감소 + 노멀/AO 베이크)을 거칩니다. 손에 쥐는 소품은 손잡이를 원점에 두고 날이 +X를 향하도록 돌려 내보냅니다. 용암 균열과 수정처럼 빛나는 부분은 `make_emit.py`가 칠한 색에서 뽑은 발광 마스크로만 빛납니다.
- **효과음**: 전투·UI 효과음 28종(화살, 마법, 대포, 폭발, 칼부림, 건설, 동전, 번개, 서리, 운석, 포효, 함성 등)은 ElevenLabs 효과음 모델로 만들었습니다. `tools/import_el_audio.py`가 버전마다 시작이 또렷하고 잡음이 적은 것을 골라 앞뒤 무음을 자르고, 원래 효과음과 같은 크기로 맞춰 Ogg로 저장합니다. 여러 버전을 번갈아 쓰는 소리(화살, 폭발, 칼 부딪힘, 칼질)는 2~3개를 남겼습니다. 나머지(오류음, 틱, 영웅 선택·이동, 집결)는 `make_audio.py`에서 numpy로 합성했습니다.
- **음성**: 영웅 3명(카엘, 세라, 렌)과 전장 안내 음성 25줄을 ElevenLabs(eleven_v4)로 녹음했습니다. 한 번에 여러 줄을 읽은 파일을 무음 구간에서 자르되, 줄마다 글자 수에 맞는 길이가 되는 자르기를 골라 "잠깐... 쉬어야겠어..." 같은 줄 안의 쉼에서 잘리지 않게 했습니다. 영웅 선택·이동·스킬·레벨업·쓰러짐·부활과 웨이브 시작·마지막 웨이브·보스 등장·승리·패배·성문 위험에서 나오고, 말하는 동안 음악 소리가 조금 줄어듭니다.
- **폰트**: Noto Sans/Serif CJK KR을 게임에 쓰인 글자만 남기도록 서브셋했습니다(`tools/make_fonts.py`). 텍스트를 추가하면 이 스크립트를 다시 실행해야 합니다.

## UI
- **스타일**: 금장 테두리 패널, 양피지 카드, 광택 버튼, 원형 슬롯, 리본 제목, 금색 그라데이션 제목을 쓰는 판타지 UI 키트입니다. Kingdom Rush 계열의 레이아웃 관례를 따릅니다(왼쪽 위 자원, 오른쪽 위 일시정지, 왼쪽 아래 영웅·주문, 건설 링 메뉴, 적 탭 시 능력치 표시).
  - `tools/make_ui_kit.py`: 키트 텍스처를 거리장(SDF)으로 2배 해상도에 그립니다.
  - `scripts/ui/stylebox_hd.gd`: 2배 텍스처를 절반 크기로 9분할해 그려 고해상도 화면에서도 선명합니다.
  - `tools/pipeline/make_icons_ui2.py`: 능력치·메뉴 아이콘을 그립니다.
- **월드맵**: 지역 선택 화면의 지도 그림은 VARCO 이미지 생성으로 만들었습니다(`assets/ui/world_map.jpg`). 깃발을 누르면 지역 브리핑 카드가 열립니다.
- **터치·가독성**: 버튼은 44pt 이상, 본문은 15px 이상입니다. 폰(짧은 변 560px 미만)에서는 960×540 캔버스를 써서 UI가 자동으로 커집니다.
- **PC 단축키**: Esc/P 일시정지, Space 다음 웨이브, F 배속, 1·2 주문, H 영웅 선택, Q 영웅 스킬. 탭이나 앱을 벗어나면 자동으로 일시정지합니다.

## 빌드
```
./tools/build_web.sh       # 임포트 → 역할별 텍스처 설정 → Web 내보내기 → 모바일 팩(ETC2) → 코어/콘텐츠 분할 → gzip 패키징
./tools/render_backdrops.sh  # 타이틀 디오라마가 바뀌면: 영웅별 배경 그림 다시 렌더링 (화면 필요, 예: Xvfb)
./tools/deploy_pages.sh    # build/web_hosted → gh-pages 브랜치 (GitHub Pages, 수동 배포용)
```
- `build/web`: 일반 Godot 웹 빌드와 `index_mobile.pck`, 그리고 각각의 콘텐츠 팩(`*_content.pck`)입니다.
- `build/web_hosted`: wasm과 pck를 gzip으로 압축해 15MB 단위로 나눈 버전입니다. 브라우저가 DecompressionStream으로 압축을 풉니다.
- 밸런스 테스트: `tools/balance.sh smart 0`(AI가 각 지역을 플레이). `skill=casual`을 붙이면 처음 하는 사람처럼 플레이합니다(느린 판단, 절반은 무작위 타워, 무작위 부지와 전문화, 특수 능력 안 삼, 주문 드물게, 영웅 조작 안 함). 난이도 인자는 0 일반, 1 영웅, 2 쉬움입니다. 화면 테스트: `tools/browser_test.py`.
- 플레이 기록 분석: 설정 → ‘플레이 기록 보내기’에서 받은 코드를 `python3 tools/playlog_decode.py <코드>`로 풀면 판마다 도달 웨이브, 웨이브별로 잃은 생명, 새어 나간 적, 지은 타워가 나옵니다.

## 코드 구조 (`scripts/`)
- `data/db.gd`: 타워(전문화·특수 능력), 적, 영웅(재능), 스펠, 강화, 업적, 레벨, 웨이브 밸런스 데이터
- `i18n/`: 언어 전환(`lang.gd`)과 영어 문자열 표(`lang_en.gd`)
- `level/level.gd`: 월드 생성(지역별 세트 피스, 맵 장치 포함), 웨이브, 경제, 선택/건설 UI 흐름, 승패 처리, 플레이 기록
- `level/cinematics.gd`: 레터박스, 지역·보스 카드, 오프닝 카메라, 슬로모션, 스토리 대화. 프레임이 길어져도 건너뛰지 않도록 프레임당 진행 시간에 상한을 둔 타임라인으로 돌립니다
- `core/`: 지형(높이맵, 버텍스 페인팅, 물, 바람에 흔들리는 풀), 경로, 카메라, 에셋 로더
- `entities/`: 적, 병사, 영웅, 타워, 투사체, 캐릭터 모델
- `fx/fx.gd`: 파티클 VFX(폭발, 마법, 번개, 화염 지대 등)
- `ui/`: HUD, 원형 건설 메뉴, 체력바 오버레이, UI 스타일
- `tools/test_runner.gd`: 자동 플레이 밸런스 테스트와 스크린샷 하네스
